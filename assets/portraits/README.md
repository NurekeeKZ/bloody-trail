# Портреты Bloody Trail

72 PNG сгенерированы собственным кодом `src/ui/portraits.py` (12 персонажей, 6 эмоций).
Это временная оригинальная пиксельная графика лица и плеч. Не используются изображения из assets/reference.
Формат замены: assets/portraits/<stable_id>/<emotion>.png, размеры с произвольным соотношением 3:4; рекомендованы 96×128 или кратные. Отсутствующая эмоция использует neutral.
Список ID и палитры находится в CHARACTERS, эмоции в EMOTIONS. Никита: тёмное пальто/красный акцент; N.U.R.S.: холодный голубой, очки, цифровые строки.

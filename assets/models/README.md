# Локальная модель речи

Папка `vosk-model-small-ru-0.22` содержит официальную малую русскую модель Vosk, лицензия Apache-2.0. Она скачана явно скриптом `tools/download_voice_model.py`; игра никогда не скачивает модели автоматически. Архив и бинарные веса исключены из Git.

Источник: [Alpha Cephei / Vosk models](https://alphacephei.com/vosk/models). Размер архива около 45 МБ. URL и вычисленный SHA-256 скачанного архива — в `voice_model_manifest.json`. Это локальный контроль целостности, не заявление о независимой сверке с опубликованной контрольной суммой.

Для переноса на другой ПК: установить `requirements-ai.txt`, выполнить `python tools/download_voice_model.py`. При отсутствии модели N.U.R.S. объяснит проблему и сохранит текстовый/кнопочный ввод. OpenCV использует поставляемые с пакетом Haar-классификаторы лица и глаз; отдельный MediaPipe не нужен.

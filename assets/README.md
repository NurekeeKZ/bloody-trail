# Графические материалы

Версия 0.3: `rooms/station.png` — собственная временная пиксельная иллюстрация кабинета; `evidence/*.png` — схематичные реконструкции фотографий/документов. Создаются `tools/build_investigation_assets.py` из code-native рендера `src/ui/investigation_art.py`. Это не финальные игровые иллюстрации. Путь фона и прямоугольники объектов разделены в JSON: замена PNG не меняет логику осмотра.

`reference/image1.png` — логотип из пользовательского Game Concept Document.
`reference/image2.png` — портрет Никиты, не используется в Beta; только исходный референс.
`reference/image3.png` — портрет N.U.R.S., не используется в Beta; только исходный референс.
`reference/image4.png`, `image5.png` — исходные визуальные референсы из того же документа.

Изображения извлечены из DOCX без изменения исходных файлов. Происхождение до включения в документ и права на коммерческое распространение не установлены.

Временная графика окружения и спрайтов создаётся `src/ui/art.py` в низком разрешении с nearest-neighbour масштабированием. Спрайт Никиты имеет состояния idle, walk и interaction (поднятый терминал). Для финального релиза нужны отдельные авторские атласы Никиты, NPC, N.U.R.S., освещение и индивидуальные локации. Соколова и Анну пока изображает общий спрайт NPC; портрет в разговоре Анны показывает слушающего Никиту и подписан соответственно.


## Beta / авторские ресурсы

`src/ui/art.py` рисует собственные пиксельные портреты; `src/ui/investigation_art.py::port_scene` — сцену порта. Изображения `reference/*` не загружаются исполняемой игрой. Для поставки исключите их до выяснения прав.

`src/systems/audio.py` генерирует PCM средствами Python: четыре ноты меню (110, 130.81, 146.83, 123.47 Гц), псевдослучайный дождь, затухающие сигналы шагов/UI/улики. Чужие записи или мелодии не использованы. Материалы созданы в рамках проекта; внешней атрибуции для этих генераторов нет.


## RC2: пролог и общий символ

`src/ui/prologue_art.py` содержит собственный пиксельный рисунок семьи/квартиры и единую геометрию трёх капель. `photo.png`, `blood.png`, обе `EVIDENCE_BLOOD_MARK_*.png` и фон кабинета регенерированы из этого символа. Звуки двери, стекла, борьбы, шороха и воспоминания синтезируются внутри проекта; записанной актёрской речи нет.

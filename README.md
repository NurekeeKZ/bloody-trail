# Bloody Trail — Windows RC1 / ЛР №14–15

Сюжетный 2D-детектив: Астера, 2035; Никита Волков, N.U.R.S., дело Левицкого и Helios Systems. Три игровых дня, шесть локаций, 12 улик, доска гипотез, два QTE, три решения Вейра и поражения. Учебная Final-сборка подготовлена; внешняя приёмка остаётся открытой.

## Запуск

Windows x64: распаковать `dist/BloodyTrail-Windows-x64-RC1.zip` **целиком** и запустить `BloodyTrail/BloodyTrail.exe`. Python встроен; папка `_internal` обязательна. Проверено на текущей Windows 11; другой чистый ПК ещё не проверялся. Внутри распакованной поставки EXE находится рядом с этим README.

Исходный проект, из `G:\bloody\bloody_trail`:

```powershell
& ..\.venv\Scripts\python.exe main.py
```

На другой машине: Python 3.12, venv, `python -m pip install -r requirements.txt`, затем `python main.py`. Сенсоры необязательны: установка `requirements-ai.txt` и модели описана в [ЛР12](docs/lab12/AI_Module_Description.md). В Windows-сборке они уже включены.

## Управление и доступ

WASD/стрелки — движение; Shift — быстрый шаг; E — взаимодействие; Tab — улики; M — карта; T/N — помощник; Esc — пауза/назад; J — ресурсы/достижения; F11 — полный экран. В расследовании B — доска, мышь — предметы/карточки. QTE: A → D → Space.

Day1 бесплатен. **Главное меню → Полная версия / доступ → Преподаватель: открыть полную версию** открывает Days2–3 локально. Реальных платежей нет. Цена $5.99 — гипотеза, DLC — неготовые закрытые карточки. Микрофон/камера включаются только после отдельного согласия; текст и кнопки равноправны.

EXE сохраняет в `%LOCALAPPDATA%\BloodyTrail\saves`, исходник — в `saves/`. `--save-dir путь` задаёт изолированный каталог. Schema v5 читает старые версии 1–4. Перед переносом делайте резервную копию; изменения формата проверяются при загрузке.

## Структура и ограничения

`src/core` — Game/SceneManager/GameState; `entities` — игрок; `systems` — доказательства/сохранения/звук/доступ; `scenes` — экраны; `ai` — независимые сенсоры/команды; `ui` — графика; `src/data` — JSON; `tests`, `tools`, `docs` — проверки и поставка.

Редактирование JSON не требует переписывать интерфейс. `tools/build_data.py` восстанавливает начальный контент и может перезаписать ручные правки; не запускать для обычной игры. Изображения `assets/reference` имеют непроверенное происхождение: runtime их не использует, сборка не включает. Процедурные графика/звук созданы для проекта; часть оформления упрощена. Лицензии зависимостей входят в THIRD_PARTY_LICENSES поставки.

Нет подтверждённого private GitHub, удалённых Issues, PR или истории двух участников. Фиктивные commits/отзывы не создавались. Продажи, готовые DLC, озвучка, подписанный установщик и автообновление не реализованы. Открытые критерии приёмки перечислены в Release Checklist.

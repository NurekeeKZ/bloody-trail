## Проверка целостности

Из корня игры: `python tools/build_lab10.py`. Генератор проверяет уникальность ID, минимальное число задач, допустимые статусы/роли/приоритеты, ISO-даты, существование зависимостей, отсутствие циклов и завершённость зависимостей у Done. Он создаёт WBS.md, WBS.json, Kanban.md и тела Issues из одного набора данных. Сеть и GitHub при этом не используются. Остаток: 122 ч, Participant 1 — 55 ч, Participant 2 — 67 ч; резерв 16 ч описан отдельно. Обновление после ЛР11 — [MVP1_Amendment.md](MVP1_Amendment.md).

Статус «выполнено» в этой таблице относится к подготовке материалов ЛР10, а не к выполнению всего будущего плана или выпуску коммерческой игры.

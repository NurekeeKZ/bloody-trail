## Правила движения

- Backlog → To Do: согласованы критерий, входные данные и доступы; незавершённая зависимость блокирует начало зависимой реализации.
- To Do → In Progress: участник действительно начал работу и создал свою ветку. Лимит — одна активная задача на участника.
- In Progress → Testing: приложены изменения и проверка разработчика. Лимит Testing — две задачи одновременно.
- Testing → Done: второй участник проверил критерий, записал результат и реальные ссылки. Для исходного среза Done означает только наличие проверенного артефакта.
- При дефекте карточка возвращается в In Progress с описанием воспроизведения; риск отмечается в Risk Register.
- Блокировка — отдельная отметка Blocked с причиной и датой, без шестой колонки. Еженедельно пересматриваются сроки и риски.
- Сначала менять ROWS в `tools/build_lab10.py`, затем пересобирать представления. После импорта в GitHub выбрать одну основную доску и явно датировать локальные снимки, чтобы они не расходились.

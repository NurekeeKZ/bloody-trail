# Проверка v0.1

Дата: 28 октября 2026. Среда: Windows, Python 3.12.14, Pygame 2.6.1, SDL 2.28.4. Зависимости установлены в локальное окружение проекта.

Выполнено `python -m unittest discover -s tests -v`: **20 тестов, 20 прошли**. Проверяются: коллизии без туннелирования, скорость по диагонали, границы камеры, близость и преграды взаимодействия, уникальность улик, неполные/полные цепочки, round-trip сохранения и повреждение, нечисловые координаты/ложные выводы, ссылки JSON, отдельные AI-примеры, возврат из осмотра на точную позицию, ограничения маршрута, сбор всех 12 улик и три финальных исхода, запрет необоснованного финала, неизвестный NLP-запрос, координаты мыши при масштабировании, загрузка повреждённого файла.

Выполнен `main.py --smoke`: отрисованы меню, исследование, осмотр, N.U.R.S., карта, диалог, инвентарь и доска. PNG просмотрены; устранены отсутствующие символы отметок и выбран читаемый кириллический шрифт. Проверка без дисплея не доказывает поведение драйвера видеокарты, живой клавиатуры или аудио.

## Ручная приёмка на компьютере команды

- Заставка → меню → новая игра; все буквы читаются.
- WASD и стрелки, Shift; нельзя пройти сквозь стол/стены.
- E не действует издалека, появляется подсказка рядом со столом.
- Выбрать объект мышью, записать улику, Esc — вернуться на ту же позицию.
- Tab показывает найденное; повторный осмотр не дублирует запись.
- Карта пропускает только открытые соседние узлы; обратный маршрут доступен.
- Ввести «сравни следы» в русской раскладке; неизвестный запрос не меняет дело.
- Сохранить, закрыть процесс, продолжить; проверить позицию, улики и выводы.
- F11 / изменение размеров: hotspots совпадают с указателем; Alt+Tab ставит на паузу.
- Пройти все узлы, подтвердить четыре цепочки, проверить три финала; отдельно подтвердить отказ от дела.

QTE, микрофон и камера отсутствуют; соответствующие сценарии приёмки Charter пока не выполнены. Два тестировщика и длительное ручное прохождение должны быть зафиксированы командой отдельно.

Дополнительно выполнен обычный оконный запуск Pygame. Через Windows UI проверены выбор hotspot «Удалённые метаданные», фиксация улики (с уведомлением и отключением повторной кнопки) и возврат кнопкой из осмотра в исследование. Инъекция Escape инструментом управления окном не дала наблюдаемого перехода; обработчик Esc подтверждён интеграционным тестом, но требует ручной проверки физической клавиатурой. Полное прохождение живой клавиатурой этим не подтверждается. После проверки окно оставлено открытым; локальное сохранение содержит тестовую находку, новая игра доступна через меню.

## Проверка GitHub

`git -C G:/bloody rev-parse --show-toplevel` → `fatal: not a git repository`. Git установлен, CLI gh не найден. Подключённой GitHub-интеграции нет. Поэтому README/.gitignore/локальные Issues проверены; удалённые Issues, commits и права доступа не проверены и не созданы. Это сохраняет реальную историю вместо искусственного её восстановления.

В `docs/lab10/issues` находятся локальные заготовки BT-задач, а не опубликованные GitHub Issues. При авторизации использовать [существующую инструкцию](../lab10/GitHub_Setup.md), предварительно просмотреть `git diff --cached`; исключить `.venv`, build/dist, пользовательские saves, downloaded model, секреты и непроверенные reference-ассеты. Добавить RC-01–05 как открытые задачи, не помечать их Done без фактов. Первый реальный коммит может честно называться снимком проверенной основы, но не имитировать месяцы работы или авторство другого студента.

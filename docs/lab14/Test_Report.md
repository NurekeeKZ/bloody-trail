# Test Report — ЛР №14 / Release Candidate 1

Срез: 29.10.2026. Среда: Windows 11 x64 (10.0.26200), Python 3.12.14, Pygame 2.6.1. Проверяется существующая кодовая база, а не отдельно написанный макет. «Pass» относится только к явно описанному способу проверки. Аппаратные и пользовательские проверки не подменяются синтетическими тестами.

- До исправлений: пять новых regression-тестов выявили пять групп дефектов (восемь failed assertions с учётом четырёх полей статистики). Протокол: [regressions_before.txt](regressions_before.txt).

- Smoke: **35 экранов**, успешная отрисовка; дополнительно четыре Beta-экрана проверяются тестами.
- Проверка исходного приложения через реальный Windows SDL-драйвер: `source_runtime.json`, passed=true.

## Воспроизведение

Из `G:\bloody\bloody_trail`:

```powershell
& ..\.venv\Scripts\python.exe -m unittest discover -s tests -v
& ..\.venv\Scripts\python.exe main.py --smoke
& ..\.venv\Scripts\python.exe main.py --release-check docs/lab15/source_runtime.json
$p = Start-Process .\dist\BloodyTrail\BloodyTrail.exe -ArgumentList '--release-check', 'G:\bloody\bloody_trail\docs\lab15\frozen_runtime.json' -PassThru -Wait
$p.ExitCode
```

Release-check открывает окно и закрывает его сам; не активирует устройства. Отчёт не доказывает субъективное качество изображения, музыки, UX, STT на живой речи или работу камеры на лице. Проверки с внешними пользователями — отдельный протокол.

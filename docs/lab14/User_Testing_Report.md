## Процедура

Камера и микрофон добровольны; отказ не мешает тесту. Один сеанс 15–20 минут: 2 минуты вступление, 10–12 минут задания, 3–5 минут анкета. До выполнения задания не подсказывать решение; помощь помечать в журнале. Использовать одинаковую версию RC1 и отдельную папку сохранений для каждого человека.

Задания: начать новую игру; найти Соколова; осмотреть стол; найти две улики; открыть инвентарь; создать вывод; пройти QTE; вызвать помощника; пройти камеру кнопками или добровольно сенсором; объяснить, что бесплатно и что открывает учебный флаг.

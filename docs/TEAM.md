# Реальная командная разработка

Этот результат не содержит подтверждённой истории участия двух студентов. Авторство нельзя заменить искусственными коммитами под чужими именами. Private GitHub-репозиторий не создан, публикация не выполнялась, имена студентов и аккаунты не заданы.

Распределение по Charter: участник 1 — программирование и интеграция; участник 2 — сценарий, дизайн, уровни и тестирование. Команда должна вписать реальные имена и самостоятельно внести проверяемый вклад.

Рекомендуемый процесс после создания private-репозитория: пригласить второго участника; каждый настраивает собственные Git name/email; вести задачи, отдельные ветки и pull requests; проверять изменения друг друга; сохранять реальные обсуждения, коммиты и результаты тестирования. Не коммитить .venv, пользовательские saves и необязательные QA-снимки.

Первая задача разработчика: QTE и контроль времени с тестами. Первая задача дизайнера: индивидуальные карта квартиры и фон осмотра, проверка канона улик, портрет Анны. Общая задача: ручное прохождение и согласование оснований финалов. Эти задания — план, не отчёт о выполненном вкладе.

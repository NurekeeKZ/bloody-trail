# Демонстрация нового эпизода (с решениями для проверяющего)

1. Новая игра → пролог (либо Esc → подтвердить пропуск) → начать расследование. F → «Исследуй территорию»: N.U.R.S. ходит по доступному полу; F → «Следуй за мной» возвращает сопровождение.
2. Подойти к Нурсултану Ермекову справа, E: виден отдельный портрет. Принять дело, если оно ещё не получено в прологе. Подойти к столу выше и нажать E.
3. Осмотреть снимок, затем удалённые метаданные терминала. На B соединить photo + metadata → создать → проверить. M → квартира; выполнить сюжетное QTE по показанным клавишам.
4. Подойти к столу квартиры, E. Обратить внимание на поднятый край ковра слева внизу. Приподнять: записка. Открыть синюю книгу: флешка, 2035 и страница 120. Журнал J хранит найденный текст.
5. Компьютер → 2035 → Enter: копия ключа и номер ячейки. Картина → сейф → 120: карточка терминала 0714. Фотографии → нажать справа внизу правой фотографии, где отсутствует печать. Получен экспертный оригинал следа.
6. B: photo + blood → создать → проверить. M → архив; на экране полной версии использовать учебную кнопку открытия. Реального платежа нет.
7. E у Мадины → предъявить поручение. На рабочем месте архива восстановить фрагменты в порядке 3–2–1; ячейка 120. B: metadata + archive, проверить при наличии sigma.
8. M → метро, пройти второе QTE. Сравнить карту с участком и квартирой. Записать показания Аружан. Айдос допускает обычные реплики, добровольную камеру или равноценную кнопочную проверку. Получить журнал.
9. Helios → терминал, ключ + карточка + 0714. На доске anna + transit при наличии pass. Далее порт → серверная копия → pass + server (при наличии archive, sigma). Передать резервную копию и предъявить проверенную цепочку Сарсенову.
10. Выбрать концовку. Арест дополнительно требует достаточных репутации и доверия Ермекова. Сохранить/загрузить можно через паузу; решения головоломок и режим N.U.R.S. сохраняются.

N.U.R.S. по T принимает существующие текстовые/голосовые команды; «Сравнить» лишь рекомендует проверку на доске. «Подсказка» раскрывает направление постепенно. Микрофон и камера добровольны и не нужны для завершения.

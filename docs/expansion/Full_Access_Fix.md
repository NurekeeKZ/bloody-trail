# Исправление доступа к полной истории — RC3.1

29.10.2026.

Исправлены два сценария: разблокировка не предлагала запуск/продолжение игры; при загрузке сохранения Day 2–3 экран доступа терял выбранный слот и требовал повторной загрузки вручную. Отказ основной кнопки открытия экрана в старой сборке не воспроизведён; новый путь проверен событием мыши из главного меню.

Теперь экран показывает карточки Day 1–3, текущий доступ и одну основную кнопку:
- «Открыть всю историю бесплатно» сохраняет учебную разблокировку.
- После разблокировки: «Начать полную историю», «Продолжить сохранённую игру» либо «Вернуться к расследованию» в зависимости от текущего состояния.
- Если экран появился при переходе или загрузке, после открытия доступа выполняется исходное действие; выбранный слот сохраняется.
- При ошибке записи нет ложного сообщения об успехе; можно повторить попытку.

Полный доступ не отменяет сюжетные требования: сначала нужны улики и выводы предыдущего дня. Настоящих платежей нет. Сохранения игрока не удаляются.

Проверки: 128 тестов PASS, из них 7 новых в `tests/test_full_access.py`. Журнал: `docs/expansion/full_access_tests.log`.
Обновлённая поставка: `dist/BloodyTrail-Windows-x64-RC3.1.zip`; исполняемый файл: `dist/BloodyTrail/BloodyTrail.exe`.
`full_access_runtime.json`: собранный EXE проверен через Windows video driver; full_access_ui=true, passed=true, код выхода 0.

# Содержание короткой презентации Bloody Trail

Формат: 8 слайдов, по 20–30 секунд; демонстрация отдельно 3–4 минуты. Это готовое содержание, не файл PowerPoint.

1. **Problem.** В коротком сюжетном детективе игроку важно самому проверять доказательства, а не угадывать готовый ответ. Цель проекта — соединить исследование мира и понятную логику расследования. Это продуктовая гипотеза, не результат проведённого опроса.
2. **Idea.** Астера, 2035. Никита Волков, дело Нурланова, убийство Сейтовых в 2020 году, Helios/«Сигма». Три дня, помощник N.U.R.S., с которым можно обсуждать дело, и выбор между законом, местью и освобождением.
3. **Game.** Top-down исследование → осмотр → улика → инвентарь → гипотеза → подтверждение → новый маршрут. Шесть локаций, 21 улика, шесть головоломок, QTE, эпизод склада с прятками и погоней, восемь развязок. Показать кабинет и доску.
4. **Target Audience.** Любители компактных сюжетных детективов и неонуарной пиксельной графики. Управление клавиатурой/мышью; устройства необязательны. Объём аудитории не измерен.
5. **Technologies.** Python 3.12, Pygame, JSON, SceneManager/GameState, отдельные системы доказательств/сохранений. Windows-сборка PyInstaller с встроенным runtime. Процедурные авторские графика и звук.
6. **AI.**
   - N.U.R.S.: речь Vosk или текст → команда либо разговор с локальной моделью (Ollama, `qwen2.5:3b`). Модель знает только найденное; код блокирует выход из роли и спойлеры; модель не меняет игру; без неё работают команды.
   - OpenCV presence/движение → короткий диалог; тишина и неподвижность → стелс.
   - Согласие, локальная обработка без интернета, без записи, кнопочные альтернативы. Software-тесты пройдены; точность на реальных пользователях не измерена.
7. **Commercialization.** Day1 бесплатно, полная история ориентировочно $5.99, будущие DLC. Реальный локальный content gate; учебный unlock без платежей. Облачных затрат на N.U.R.S. нет — модель работает на ПК игрока. Спрос и доход пока гипотезы, а не подтверждённые показатели.
8. **Result.** Запускаемый Windows RC4.1, 191 автоматический тест, восемь развязок и поражения, разговорный N.U.R.S. Следующие обязательные шаги: чистый ПК, живая речь/камера, 3 внешних теста, художественная доработка и реальная история команды в GitHub.

Иллюстрации: собственные `docs/screenshots` и `docs/lab15/frozen_runtime.png`. Не ставить чужие портреты из `assets/reference` на публичные слайды без проверки прав. На заключительном слайде показать ссылку/QR на реальный репозиторий только после его создания.

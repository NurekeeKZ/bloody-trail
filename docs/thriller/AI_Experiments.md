# Проверка сигналов: выполненные и непроведённые испытания

30.10.2026. Данные ниже не являются измерением точности на реальных пользователях.

| Эксперимент | Вход | Фактический результат |
|---|---|---|
| Калибровка шума | Числовой -65 dBFS в течение 2,1 с | Порог -53 dBFS |
| Тишина | Числовой -65 dBFS, движение 0,02 | Успех по завершении 15 с |
| Краткий импульс | Числовой 0 dBFS, 0,2 с, затем тишина | Обнаружения нет, опасность падает до 0 |
| Продолжительный звук | Числовой -5 dBFS | Ветка noise |
| Продолжительное движение | Числовое движение 2,0 | Ветка motion |
| Ненадёжные признаки | reliable=False | Таймер и опасность не растут |
| Камера, пустой кадр | Синтетическое чёрное RGB-изображение | Лицо не найдено |
| Изменение освещения | Текстурное изображение +40 яркости; рамка лица задана тестом | lighting=True, reliable=False |
| Неподвижность | Один и тот же текстурный кадр, заданная рамка лица | reliable=True, motion<0,03 |
| Движение в ROI | Сдвиг текстуры области тела на 5 пикселей; заданная рамка лица | reliable=True, motion>0,3 |
| Два потока в сцене | Подставленные свежие события камеры/микрофона | Калибровка и успешный исход через реальную сцену |
| Отказ устройства | Подставленный OSError | Захват закрыт, ручной режим доступен, последствий нет |

Источник результатов: тесты `StealthSignalTests` и `ThrillerIntegrationTests`; повторить `python -m unittest discover -s tests -p test_thriller.py -v`.

## Воспроизводимый протокол аппаратной проверки — NOT RUN

Открыть отдельный демонстрационный слот, не личное сохранение. На складе выбрать «Микрофон + камера», прочитать согласие. Проверить индикаторы и калибровку. Не снимать/сохранять видео: вручную записывать только условия, уровни, результат и длительность.

| Сценарий | Ожидается | Фактический результат |
|---|---|---|
| Тихая комната, неподвижный игрок, фронтальный свет | Успех | NOT RUN |
| Вентилятор/постоянный негромкий фон | Калибровка компенсирует фон | NOT RUN |
| Один короткий кашель/хлопок | Нет моментального обнаружения | NOT RUN |
| Громкая речь несколько секунд | Опасность и погоня | NOT RUN |
| Небольшие естественные движения головы | Допуск без провала | NOT RUN |
| Продолжительное резкое движение рук внутри ROI | Рост опасности, ветка ранения | NOT RUN |
| Резкая смена общей яркости | Ненадёжный сигнал, пауза таймера | NOT RUN |
| Движущийся фон с неподвижным игроком | Не должен давать ложный провал; измерить ограничение ROI | NOT RUN |
| Лицо вне кадра / тёмная комната | Пауза, затем предложение ручного режима | NOT RUN |
| Отключение USB-камеры / микрофона | Ошибка без зависания, освобождение второго устройства | NOT RUN |
| Esc / потеря фокуса / выход / загрузка | Оба индикатора и захват выключены | NOT RUN |
| Другой чистый Windows-ПК | EXE запускается без Python | NOT RUN |

Если признаки неустойчивы, использовать кнопочный режим. Уменьшение чувствительности не должно скрывать необходимость тестирования. Optical flow по области тела не гарантирует распознавание каждого движения руки или отделение любого фона. Live accuracy не измерялась.

# Лабораторная работа №9 — требования и UI/UX

Версия 0.2 расширяет существующую архитектуру: SceneManager, GameState и системы улик, диалогов, перемещения и NLP сохранены.

Материалы для сдачи:

1. [Requirements Specification](requirements_specification.md) — 20 функциональных и 9 нефункциональных требований с ID, критерием проверки и приоритетом.
2. [User Stories](user_stories.md) — 10 историй As a / I want / So that и Given / When / Then.
3. [MoSCoW](moscow.md) — приоритеты и границы этапа.
4. [UI/UX Prototype](ui_ux_prototype.md) — схема шести экранов, персонажи, мир и маршрут кликабельного прототипа.
5. [Отчёт о проверке](verification.md) — 37 тестов, визуальная проверка и ручной чек-лист.

Запуск: `G:\bloody\bloody_trail\run.bat`. Если прежний процесс игры ещё открыт, закройте его обычным способом и запустите заново: изменения Python-файлов не подменяют уже загруженные классы.

Реализованы интерактивные Start, Main Menu, Game, Pause/Settings, Results, Game Over; авто/ручной/checkpoint слоты; настройки; hover/click; fullscreen; таймер; каталог DLC. Здоровье и репутация отображаются из состояния без новых сюжетных последствий. QTE — рабочая тренировка. Согласия камеры/микрофона — локальные предпочтения без доступа к устройствам. DLC заблокированы, платежей нет.
